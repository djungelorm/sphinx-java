v1.0.0
 * Rename the package from javasphinx to sphinx-java, and the extension from javasphinx to sphinx_java
 * Require Python 3.11+ and Sphinx 7.2+
 * Remove javasphinx-apidoc and its dependencies
 * Parse signatures with tree-sitter-java instead of javalang
 * Support parallel builds
 * Show type parameters and primitive types as plain text
 * Link the package of a qualified type name as one package reference
 * Fix package references, which linked to a missing target
 * Resolve an any reference to one Java object
 * Leave out the leading space of a signature without modifiers
 * Link to the external docs of a package in javadoc_url_map
 * Warn about a java:extdoc target with no external docs, instead of stopping the build
 * Report an error for a field directive that declares several fields
 * Report a syntax error for an unterminated literal or a signature that ends early, instead of stopping the build
 * Link to the Java SE docs with https
 * Link a generic type in a role or doc field, such as List<String>, to the type
 * Show the throws clause of a method or constructor signature
 * Link the exception types in the throws field of a constructor
 * Link the bounds of type parameters in signatures
 * Show the type parameters of a constructor signature
 * Link to the Java SE 25 docs, and choose the version with javadoc_java_se_version
 * Fix the javadoc8 anchors of methods with several parameters or array parameters
 * Show the default modifier of an interface method
 * Show the initializer of a field as written, such as -1 or Integer.MAX_VALUE
 * Show the annotations of a declaration or parameter, and final parameters
 * Add the java:enumconstant directive
 * Support records and compact constructors
 * Support sealed and non-sealed types, and permits clauses
 * Support type annotations and receiver parameters
 * Show the default value of an annotation element
 * Fix a crash on a signature that ends with the number 0
 * Show modifiers in the order of the Java Language Specification, such as abstract static
 * Keep an annotation written after the modifiers, such as public @Nullable String, in its place
 * Link a nested type of an imported or java.lang type, such as Map.Entry, and an imported nested type by its simple name
 * Link the java.lang types added since Java 8, such as FunctionalInterface and Record
 * Fix a syntax error on an array cast in a field initializer, such as (int[]) x
 * Fix a crash on an enum constant with unclosed arguments, such as RED(a
 * Ship type hints (py.typed)
