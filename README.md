# sphinx-java

A Sphinx domain for documenting Java APIs. It is a fork of [javasphinx](https://github.com/bronto/javasphinx), which is no longer maintained, without the `javasphinx-apidoc` tool.

## Usage

Install using pip:

```
pip install sphinx-java
```

Enable the extension in your `conf.py`:

```py
extensions = ['sphinx_java']
```
